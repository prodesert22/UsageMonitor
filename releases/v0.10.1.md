# v0.10.1

First release with Linux distribution packaging: every GitHub release now
ships prebuilt artifacts alongside crates.io — `.deb`, `.rpm`, Arch
`.pkg.tar.zst`, `.AppImage`, a Flatpak manifest, and a generic `.tar.gz`.

## Added

- **Distribution packages.** Each release publishes `usage-monitor-cli`
  as a Debian/Ubuntu `.deb`, Fedora/RHEL `.rpm`, Arch binary package
  (`usage-monitor-cli-bin`), portable `.AppImage`, Flatpak manifest with a
  vendored-source bundle, and a generic `.tar.gz` (binary, completions, man
  page, `install.sh`). All formats ship the same payload, including the
  embedded KDE, Waybar, and GNOME widgets.
- **`generate-dist` subcommand (hidden).** `usage-monitor-cli generate-dist
  <dir>` emits shell completions (bash/zsh/fish/powershell/elvish), the man
  page, and the Debian changelog from the live clap definition, so packagers
  never drift from the real CLI surface.
- **Packaging validation in CI.** `dist-check` (static), `dist-build` (real
  Debian install, Fedora RPM install in a container, Arch
  build/install in a container, AppImage execution), and `flatpak-build`
  (offline build from the current commit) run on every push; releases stay
  draft until all packaging, Flatpak, and crate-publishing jobs succeed.

## Fixed

- Debian dependencies are detected from the build environment; the Flatpak
  build uses the Rust SDK extension and exports the app icon correctly.
- Asset generation no longer depends on valid user configuration; AppImage
  icon metadata and tool extraction work without FUSE.
- The AppImage payload builds on Ubuntu 22.04 (GLIBC 2.34 baseline) so one
  binary runs on current and older distributions.

## Install

```bash
sudo dpkg -i usage-monitor-cli_0.10.1-1_amd64.deb          # Debian/Ubuntu
sudo rpm -i usage-monitor-cli-0.10.1-1.x86_64.rpm          # Fedora/RHEL
sudo pacman -U usage-monitor-cli-bin-0.10.1-1-x86_64.pkg.tar.zst  # Arch
tar -xzf usage-monitor-cli-0.10.1-linux-x86_64.tar.gz && ./usage-monitor-cli-*/install.sh  # anywhere
chmod +x UsageMonitor-0.10.1-linux-x86_64.AppImage         # portable
```

See [docs/installation.md](https://github.com/prodesert22/UsageMonitor/blob/v0.10.1/docs/installation.md) for the Flatpak build
and every format in detail.
