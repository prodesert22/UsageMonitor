# v0.7.2

Fixes the Kimi provider's absence from the KDE widget UI and the CLI widget
payload, and delivers a thorough multi-account documentation rewrite.

## Added

- **Kimi provider in KDE widget.** The provider now shows in the widget
  settings panel (`PROVIDER_NAMES`, `CONNECT_HINTS`) and the CLI widget
  payload renders `"Kimi"` instead of the generic fallback.
- **Kimi token extraction guide.** `docs/providers/kimi.md` now walks through
  copying the `kimi-auth` JWT from browser DevTools, with env-var, CLI, and
  inline config setup options.
- **Multi-account documentation overhaul.** `docs/providers/README.md` replaces
  the brief overview with a full reference:
  - Auth-type table (API key / token-cookie / OAuth / manual) mapping every
    provider to its multi-account strategy.
  - `CODEX_HOME` isolation walkthrough for Codex (`codex login` per account).
  - `HOME` isolation walkthrough for Claude (fake `$HOME` per login).
  - `credentials_path` examples for Gemini and Antigravity.
  - Per-provider config keys table (`api_key`, `token`, `credentials_path`,
    `base_url`, …).
  - Auto-detected default behaviour explained with disable example.

## Changed

- Workspace crate version and KDE plasmoid metadata bumped to `0.7.2`.

## Install

```bash
cargo install usage-monitor-cli
usage-monitor-cli widget install kde
```
