# v0.10.5

Tab completion for the Usage Monitor CLI. Completing a partial command fills
in the command name; completing after a command lists its options and supported
values, including provider names and widget targets. Shells that display
completion descriptions show the command help text alongside suggestions.

## Added

- `usage-monitor-cli completions <shell>` prints completion code for Bash,
  Zsh, Fish, PowerShell, and Elvish. The same definitions generate the files
  bundled with native packages and the generic tarball.
- README and installation guides show the lines to copy into the Bash, Zsh,
  or Fish startup file after a Cargo install. Packaged installs already place
  completion files in the shell's system directory.

## Install

```bash
sudo dpkg -i usage-monitor-cli_0.10.5-1_amd64.deb          # Debian/Ubuntu
sudo rpm -i usage-monitor-cli-0.10.5-1.x86_64.rpm          # Fedora/RHEL
sudo pacman -U usage-monitor-cli-bin-0.10.5-1-x86_64.pkg.tar.zst  # Arch
tar -xzf usage-monitor-cli-0.10.5-linux-x86_64.tar.gz && ./usage-monitor-cli-*/install.sh  # anywhere
chmod +x UsageMonitor-0.10.5-linux-x86_64.AppImage         # portable
flatpak install --user UsageMonitor-0.10.5-linux-x86_64.flatpak  # flatpak
```

For a Cargo install, run `cargo install usage-monitor-cli`, then copy the
completion line for your shell from the
[installation guide](https://github.com/prodesert22/UsageMonitor/blob/v0.10.5/docs/installation.md#cargo-install)
into its startup file.
