# v0.10.3

Release now ships a prebuilt single-file `.flatpak` bundle, completing the
distribution matrix: `.deb`, `.rpm`, Arch `.pkg.tar.zst`, `.AppImage`,
`.flatpak`, and generic `.tar.gz`. No provider or widget behavior changes;
all version surfaces bumped to 0.10.3.

## Added

- **Prebuilt Flatpak bundle.** Each release publishes
  `UsageMonitor-<version>-linux-x86_64.flatpak` via `flatpak build-bundle`
  in the release workflow, with the Freedesktop 24.08 runtime referenced
  from Flathub. The bundle is currently unsigned, so `flatpak install`
  shows a signature warning; GPG signing in CI is a follow-up.

## Fixed

- **Release-notes links.** Relative links (`../docs/...`) 404'd on the
  GitHub release page, which has no file context. Notes now use absolute
  tag-pinned blob URLs.

## Install

```bash
sudo dpkg -i usage-monitor-cli_0.10.3-1_amd64.deb          # Debian/Ubuntu
sudo rpm -i usage-monitor-cli-0.10.3-1.x86_64.rpm          # Fedora/RHEL
sudo pacman -U usage-monitor-cli-bin-0.10.3-1-x86_64.pkg.tar.zst  # Arch
tar -xzf usage-monitor-cli-0.10.3-linux-x86_64.tar.gz && ./usage-monitor-cli-*/install.sh  # anywhere
chmod +x UsageMonitor-0.10.3-linux-x86_64.AppImage         # portable
flatpak install --user UsageMonitor-0.10.3-linux-x86_64.flatpak  # flatpak
```

See [docs/installation.md](https://github.com/prodesert22/UsageMonitor/blob/v0.10.3/docs/installation.md)
for every format in detail.
