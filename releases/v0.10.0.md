# v0.10.0

Adds the GNOME Shell extension to Usage Monitor, including a top-bar indicator,
a usage popup, and native preferences for managing providers and accounts.

## Added

- **GNOME Shell extension (45–49).** Install it from the CLI with
  `usage-monitor-cli widget install gnome`. The `widget gnome` command emits
  the same data contract as the KDE and Waybar widgets.
- **Top-bar usage indicator.** Show selected Session (5h), Weekly, and Monthly
  percentages, or pin the display to a provider/account.
- **Usage popup.** View one card per provider/account, with usage windows, reset
  times, stale/error status, account details, and 30-day cost when available.
- **GNOME Preferences.** General, Providers, Order, Theme, Updates, and About
  pages. Providers are loaded from the CLI catalog and can be enabled or
  disabled; named accounts can be added and removed using provider-specific
  credential forms and sign-in instructions.
- **Account setup from Preferences.** Secret fields are masked in the form.
  The extension sends their values to the CLI through stdin instead of process
  arguments. The About page includes a clickable project website.

## Fixed

- GNOME live data now replaces the initial placeholder after the CLI process
  completes. Failed refreshes keep the last successful payload and mark it
  stale with an error notice.
- The extension prefers user-installed CLI binaries and falls back to the
  compatible `widget kde` payload when an older CLI does not implement
  `widget gnome`.
- Popup cards and progress bars now use the available width, and the panel
  percentages align with the icon. The panel displays each selected usage
  window instead of a single overall value.
- GNOME theme preferences now apply palettes, background opacity, progress-bar
  height, and card corner radius. User-defined account labels containing
  “auto-detected” keep their Remove action.
- CLI output fully redacts configured secrets instead of showing a prefix.

## Install

```bash
cargo install usage-monitor-cli
usage-monitor-cli widget install gnome
gnome-extensions enable usage-monitor@usage-monitor.dev
```

On Wayland, log out and back in after installing or updating extension code so
GNOME Shell loads the new files. Refreshing usage data does not need a new
session.
