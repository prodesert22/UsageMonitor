# v0.10.4

Antigravity usage without a credentials file: the provider reads the local
`agy` CLI report (`agy -p /usage`) as its primary source, showing the weekly
Gemini and Claude/GPT quota windows, with the plan label resolved best-effort
(`paidTier.name` such as `Plus` wins). Widgets show the real window names and
no longer render duplicated values. All version surfaces bumped to 0.10.4.

## Added

- **Antigravity `agy` CLI source.** `fetch antigravity` runs
  `agy -p /usage --output-format json` and parses the weekly quota groups
  (CodexBar's `antigravity.cli-https` print-report path): Gemini weekly as the
  primary window, Claude/GPT weekly as secondary, every bucket also in the
  named extra windows. No credentials file needed; auto-enables when `agy` is
  installed and has run as the current user. The OAuth remote path
  (`fetchAvailableModels` / `retrieveUserQuota`) remains as fallback.
- **Antigravity plan label.** Best-effort `loadCodeAssist` enrichment whenever
  OAuth credentials exist, mirroring CodexBar: `paidTier.name` (e.g. `Plus`)
  wins, then `planInfo.planType`, then the current tier
  (`standard-tier` → `Paid`, `free-tier` → `Free`, `legacy-tier` → `Legacy`).

## Changed

- Widget cards and tooltips (KDE, Waybar, GNOME) show the real window names
  from the CLI payload (e.g. `Gemini weekly`, `Claude/GPT weekly`,
  `Session (5h)`) instead of the generic Session/Weekly/Monthly slot names.
- Antigravity remote fallback plan label is now `Antigravity` (was
  `Code Assist`) for consistency across sources.

## Fixed

- Named extra windows duplicating a primary/secondary/tertiary window are no
  longer emitted by the widget payload (they rendered every value twice in
  tooltips and the GNOME panel list).

## Install

```bash
sudo dpkg -i usage-monitor-cli_0.10.4-1_amd64.deb          # Debian/Ubuntu
sudo rpm -i usage-monitor-cli-0.10.4-1.x86_64.rpm          # Fedora/RHEL
sudo pacman -U usage-monitor-cli-bin-0.10.4-1-x86_64.pkg.tar.zst  # Arch
tar -xzf usage-monitor-cli-0.10.4-linux-x86_64.tar.gz && ./usage-monitor-cli-*/install.sh  # anywhere
chmod +x UsageMonitor-0.10.4-linux-x86_64.AppImage         # portable
flatpak install --user UsageMonitor-0.10.4-linux-x86_64.flatpak  # flatpak
```

See [docs/installation.md](https://github.com/prodesert22/UsageMonitor/blob/v0.10.4/docs/installation.md)
for every format in detail.
